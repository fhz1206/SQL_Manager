# SQLite 数据库管理工具

一个功能强大、界面现代化的 SQLite 数据库可视化管理工具，基于 PyQt5 开发，提供直观的图形界面来管理 SQLite 数据库。

## 功能特性

### 🗄️ 数据库管理
- 打开现有的 SQLite 数据库文件（.db, .sqlite, .sqlite3）
- 创建新的 SQLite 数据库
- 关闭当前数据库
- 数据库对象树形浏览

### 📊 数据表操作
- 查看表结构和数据
- 支持数据搜索和过滤
- 多列搜索功能
- 实时显示行数统计
- 右键菜单快捷操作

### 🔍 查询向导
- 可视化构建 SQL 查询语句
- 支持选择表和列
- 多条件筛选（AND/OR 逻辑）
- 支持多种比较操作符
- 排序功能
- 实时预览生成的 SQL 语句

### 💻 SQL 查询编辑器
- 自定义 SQL 查询语句
- 执行查询并显示结果
- 清空编辑器功能
- 结果表格展示

### 🎨 界面特性
- 现代化扁平设计风格
- 深色主题 SQL 编辑器
- 响应式布局
- 表格交替行颜色
- 自定义滚动条样式
- 友好的状态栏提示

## 安装说明

### 环境要求
- Python 3.6 或更高版本

### 依赖安装
```bash
pip install -r requirements.txt
```

或手动安装依赖：
```bash
pip install PyQt5>=5.15.0
```

## 使用方法

### 启动应用
```bash
python app.py
```

### 基本操作
1. **打开数据库**
   - 点击工具栏的 "📂 打开数据库" 按钮
   - 选择 SQLite 数据库文件

2. **创建数据库**
   - 点击工具栏的 "➕ 新建数据库" 按钮
   - 输入数据库名称并保存

3. **浏览数据表**
   - 在左侧数据库对象树中点击表名
   - 右侧将显示表的数据内容

4. **使用查询向导**
   - 在数据表选项卡点击 "🔍 查询向导" 按钮
   - 按照向导步骤选择表、列和条件
   - 点击 "▶ 执行查询" 查看结果

5. **执行自定义 SQL**
   - 切换到 "💻 SQL查询" 选项卡
   - 在编辑器中输入 SQL 语句
   - 点击 "▶ 执行查询" 查看结果

6. **搜索数据**
   - 在搜索框中选择要搜索的列
   - 输入关键词进行实时搜索
   - 点击 "清除" 按钮重置搜索
